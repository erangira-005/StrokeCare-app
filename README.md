# Hand-off zips (not part of the app)

One zip per team member with only their own files, made by `python tools/make_handoff.py` from `main`
(230 files in total, each with exactly one owner in `OWNERS.json`). They are identical to the files on `main`.
You can make the same zips yourself: clone `main` and run that command.

This branch only exists to hand the zips out. Do not merge it. Delete it when everyone has their files.
